# Mobile Shop Website

## Project Description
A responsive mobile shop website developed using HTML and CSS.

## Features
│── index.html
│── products.html
│── product.html
│── about.html
│── contact.html
│── style.css

9 HTML pages (index, Home, Products, About, Contact, apple, samsung, pixel, oneplus)
Single shared CSS file
Responsive layout using Flexbox
Product cards with images
Product details table
Contact form
Simple navigation bar and footer

## Technologies Used
- HTML5
- CSS3
